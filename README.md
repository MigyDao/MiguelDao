# Miguel Francis — Personal Portfolio V2

Responsive personal portfolio for Miguel Francis.

## Positioning

**Maker · Systems Thinker · Operations & Design**

> I design practical systems, products and workflows where physical work, people and technology meet.

## Stack

- Semantic HTML
- CSS
- Minimal vanilla JavaScript
- GitHub Pages

The site is intentionally framework-free and lightweight so it is easy to maintain and fast on modest hardware and mobile connections.

## Evidence policy

Portfolio claims should be traceable to documented project, employment or system evidence. Historical metrics that are still being reconciled are intentionally omitted rather than presented as facts.

## Local preview

Open `index.html` in a browser, or serve the folder using any simple static web server.
